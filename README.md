# Focus Mode

Расширение для Chrome (Manifest V3), которое блокирует отвлекающие сайты на время учёбы.

## Установка

1. Открой Chrome и перейди по адресу `chrome://extensions`.
2. Включи **Режим разработчика** (переключатель в правом верхнем углу).
3. Нажми **Загрузить распакованное расширение**.
4. Выбери папку с расширением (`chrome-focus-mode`).
5. Расширение появится в списке — можно закрепить иконку на панели.

## Использование

- Нажми на иконку Focus Mode.
- Введи количество минут и нажми **Включить фокус**.
- Пока таймер активен, отвлекающие сайты будут показывать красный экран «Вернись к работе!».
- Кнопка **Выключить** завершает сессию досрочно.

## Файлы

- `manifest.json` — конфигурация расширения.
- `popup.html` / `popup.js` — интерфейс таймера.
- `content.js` / `style.css` — блокировка страниц.
