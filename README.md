# Focus Mode

Расширение для Chrome (Manifest V3), которое блокирует отвлекающие сайты на время учёбы или работы.

## Установка

1. Открой Chrome и перейди по адресу `chrome://extensions`.
2. Включи **Режим разработчика** (переключатель в правом верхнем углу).
3. Нажми **Загрузить распакованное расширение**.
4. Выбери папку с расширением (`chrome-focus-mode`).
5. Расширение появится в списке — можно закрепить иконку на панели.

## Использование

- Нажми на иконку Focus Mode.
- Введи количество минут (от 1 до 600) и нажми **Включить фокус**.
- Пока таймер активен, отвлекающие сайты будут показывать красный экран «Вернись к работе!».
- Кнопка **Выключить** завершает сессию досрочно.

## Режимы блокировки

- **Блокировать всё** — блокируются все сайты, кроме перечисленных в списке исключений. Подходит для режима «полный цифровой детокс».
- **Только список** — блокируются только сайты из списка и их поддомены. Подходит, чтобы убрать конкретные отвлекающие сервисы.

Список сайтов задаётся в popup (по одному на строку, можно через запятую). Домены указываются без протокола, например `youtube.com` — это также заблокирует `m.youtube.com` и `www.youtube.com`.

## Файлы

- `manifest.json` — конфигурация расширения.
- `popup.html` / `popup.js` — интерфейс таймера и настройка списка сайтов.
- `content.js` / `style.css` — блокировка страниц.
- `icons/` — иконки расширения.
- `scripts/gen-icons.js` — генератор иконок (`node scripts/gen-icons.js icons`).
